### Step 4: Create Convex Queries & Mutations

Example files to create:

#### `convex/articles.ts` - Article queries
```typescript
import { query, mutation } from "./_generated/server";
import { v } from "convex/values";

export const getPublished = query({
  handler: async (ctx) => {
    return await ctx.db
      .query("articles")
      .filter((q) => q.eq(q.field("status"), "published"))
      .order("desc")
      .collect();
  },
});

export const getById = query({
  args: { id: v.id("articles") },
  handler: async (ctx, args) => {
    return await ctx.db.get(args.id);
  },
});

export const create = mutation({
  args: {
    title: v.string(),
    content: v.string(),
    // ... other fields
  },
  handler: async (ctx, args) => {
    return await ctx.db.insert("articles", args);
  },
});
```

## ⚠️ Important Considerations

### 1. Authentication Migration
Supabase Auth needs to be replaced with:
- **Clerk** (recommended) - Drop-in authentication
- **Auth0** - Enterprise-grade auth
- **Custom JWT** - Build your own

User passwords from Supabase cannot be directly migrated. Options:
- Force password reset for all users
- Implement "magic link" authentication
- Use social OAuth providers

### 2. Foreign Key Relationships
Convex uses document IDs instead of UUIDs:
- Map old UUIDs to new Convex IDs during import
- Update all foreign key references
- Save mapping in `_id_mappings.json` for reference

### 3. Real-time Subscriptions
Supabase real-time → Convex reactive queries:
```typescript
// Supabase
supabase
  .from('articles')
  .on('INSERT', payload => console.log(payload))
  .subscribe();

// Convex (automatic reactivity)
const articles = useQuery(api.articles.getAll);
// Component re-renders automatically on data changes
```

### 4. Row Level Security (RLS)
Supabase RLS → Convex function-level auth:
```typescript
// Add auth checks in Convex functions
export const getMyArticles = query({
  handler: async (ctx) => {
    const identity = await ctx.auth.getUserIdentity();
    if (!identity) throw new Error("Unauthorized");

    return await ctx.db
      .query("articles")
      .filter((q) => q.eq(q.field("author_id"), identity.subject))
      .collect();
  },
});
```

### 5. Edge Functions
Supabase Edge Functions → Convex Actions:
- `send-email/` → Create `convex/email.ts` action
- `invitation-tokens/` → Create `convex/invitations.ts` action
- Actions can call external APIs (Resend, etc.)
