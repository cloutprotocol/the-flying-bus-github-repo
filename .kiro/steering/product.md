# Product Overview

This is an interactive news platform designed specifically for kids, featuring Web3 integration and gamification elements.

## Core Features

- **Interactive News Platform**: Kid-friendly news articles across multiple categories (Headliners, Debates, Learning, Neighborhood, School News, Spice It Up, Storyboard)
- **Web3 Integration**: Crypto wallet support with Thirdweb SDK for embedded wallets and social login
- **Token Rewards System**: Users earn tokens for engagement (reading articles, completing tasks, referrals)
- **Social Features**: Comments, user profiles, activity feeds
- **Content Management**: Admin portal for article management, moderation, and analytics
- **Authentication**: Multiple auth methods including email, Google, Apple via Supabase

## Target Audience

Children and young readers, with appropriate content moderation and safety features.

## Key Categories

- **Headliners**: Main news stories
- **Debates**: Discussion-based content with voting
- **Learning**: Educational content
- **Neighborhood**: Local community news
- **School News**: School-related updates
- **Spice It Up**: Entertainment content
- **Storyboard**: Episodic story content

## Reward System

Token-based engagement system with rewards for various user actions (task completion, reading, referrals, quiz completion).
