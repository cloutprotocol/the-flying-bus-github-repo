# Product Overview

"The Flying Bus: News for Kids, By Kids" is an interactive news platform designed for children. The platform enables young journalists to create, publish, and share news content while providing a safe, moderated environment for young readers.

## Key Features

- **Content Creation**: Rich text editor with kid-friendly features for article creation
- **Web3 Integration**: Thirdweb wallet integration with token rewards system
- **Social Authentication**: Email, Google, and Apple login options
- **Safety First**: Comprehensive moderation system with content screening and reporting
- **Interactive Elements**: Comments, likes, debates, and voting features
- **Role-Based Access**: Readers, authors, moderators, and admin roles
- **Educational Focus**: Age-appropriate content with accessibility considerations

## Content Categories

- Headliners (main news)
- School News
- Debates (with voting)
- Learning (educational content)
- Neighborhood (local news)
- Spice It Up (entertainment)
- Storyboard (serialized content/episodes)

## Target Audience

Primary users are children and young journalists, with safety and educational value as core priorities. All features should be designed with age-appropriate interfaces and content moderation.
